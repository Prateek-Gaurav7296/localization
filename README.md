# localization

Shared workspace for the localization pipeline. Each developer works in their own folder;
the pieces are combined later into an end-to-end application.

| Folder | Owner |
|--------|-------|
| `Prateek/` | Prateek |
| `Swati/`   | Swati   |
| `Ishnit/`  | Ishnit  |

Keep changes inside your own folder to avoid merge conflicts, and document each module's
inputs, outputs and how to run it in a `README.md` in that folder so it can be wired together later.
